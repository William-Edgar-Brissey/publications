Rain vs a real El Niño index (RQ5 v0 — not a cause)

How to read a number

  1. What instrument? 2. What month vs that month’s 1991–2020 mean? 3. Is the source late or empty? 4. Which claim ID, if any, is allowed to move?

If those four are missing, treat the number as decoration.
