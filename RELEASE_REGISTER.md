## Release control

A document must not be marked `PUBLISHED` until:
1. the public source is committed;
2. the site build succeeds;
3. the public URL resolves;
4. the release register is updated with that URL;
5. any PDF advertised by the article resolves and renders.

Failures remain visible and do not block publication when the failure itself is part of the reported evidence and the claim boundary is honest.
